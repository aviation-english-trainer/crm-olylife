# Script serveur (Google Apps Script)

Copie de référence du script `Code.gs` du CRM OlyLife — WLHT. Le fichier le plus récent est la version à coller dans Apps Script
(Déployer → Gérer les déploiements → ✏️ → Nouvelle version). Les clés (SIO_API_KEY, ONESIGNAL_KEY, CALENDLY_TOKEN, SIO_HOOK_SECRET)
sont dans les Propriétés du script, jamais ici.
